# Leon 人生体验与旅行推荐

本文件属于第 4 层“Skill 知识文档层”的 reference 草案。它基于第 3 层 `evidence.jsonl` 中的 `ev_experience_*` 证据卡整理，用于回答“如果按 Leon 的体验观，某个地方有什么好玩/值得体验/独特体验”的问题。

## 总纲

Leon 的旅行推荐不只是景点清单，而是“人生体验账本”的一部分。回答这类问题时，不要只说哪里漂亮，而要问：

- 这个地方能打开哪一种体验：节庆、自然、身体挑战、本地生活、童心、浪漫、精神性、亲子、社群？
- 这个体验是否有时间窗口：季节、年龄、身体状态、节日日期、家庭阶段？
- 它是单纯消费，还是能转化成记忆、关系、身体感受、文化理解和自我发现？
- 当前资料是否真的有 Leon 相关证据，还是只能用 Leon 的框架推演？

如果用户问当前开放时间、价格、签证、天气、安全、路线交通、预订方式，要把这些和 Leon 证据分开。Leon Skill 只提供“Leon 公开内容中出现过的体验线索”；实时旅行信息需要另行核对。

## 回答边界

可以说：

- “Leon 在这个视频里体验/推荐过类似玩法。”
- “基于 Leon 的体验观，这个地方不只是打卡，可以这样玩。”
- “目前 skill 里有这个地点的证据，但路线细节不足。”

不要说：

- “这是 Leon 本人现在最推荐的地方。”
- “这个活动现在一定开放/价格一定如此。”
- “Leon 做过完整攻略”，除非证据真的支持。

## 推荐框架

遇到“某地有什么好玩”时，按这个顺序回答：

1. 先列出当前 evidence 里有证据的体验。
2. 按体验类型分组，而不是按景点堆砌。
3. 每个体验说明适合什么样的人。
4. 用 Leon 的价值观补一句：这个体验为什么值得进入人生账本。
5. 引用视频标题、时间段和 URL。
6. 如果用户需要现实规划，提醒开放时间、价格、季节、安全需要另查。

## 泰国

### 曼谷：泼水节

适合：

- 想体验高能量街头节庆。
- 喜欢热闹、陌生人互动、城市公共空间变成派对。
- 不介意人多、湿身、交通混乱。

Leon 资料里的体验线索：

- 街上有密集人群、水枪、街头蹦迪。
- 有不同年龄、不同种族的人一起喷水。
- 现场还出现跨文化相遇和拥抱的片段。

证据：

- `ev_experience_001`: 曼谷泼水节，00:03:04-00:04:08。

### 清迈：天灯节

适合：

- 想体验仪式感、集体祝愿和视觉震撼。
- 喜欢节庆、光、夜晚氛围。
- 适合亲子，但需要注意人流和安全。

Leon 资料里的体验线索：

- 放水灯、诵经、成千上万天灯升空。
- 天灯升起时现场像星星和银河。

证据：

- `ev_experience_002`: 清迈天灯节，00:02:12-00:03:16。

### 清迈：香巴拉音乐节

适合：

- 想体验精神性、社群感、自由灵魂和音乐节氛围。
- 对“像部落一样坐在地上”的松弛场域感兴趣。

## 尼泊尔

### EBC 徒步

适合：

- 想用身体进入自然。
- 想挑战自己，而不是只看风景。
- 能接受高海拔、长时间徒步、基础设施较简单的人。

Leon 资料里的体验线索：

- 路上有村庄、吊桥、瀑布、牦牛队和垂直爬升。
- 进入山里后通信逐渐减少。
- 到珠峰大本营时，体验可以变成人生仪式：生日、纪念日、阶段转换。

证据：

- `ev_experience_008`: EBC 第一天徒步体验，00:10:19-00:11:53。

## 按体验类型推荐

如果用户没有指定地点，只问“Leon 会推荐什么独特体验”，可以按类型回答：

- 节庆与集体能量：曼谷泼水节、清迈天灯节、伦敦圣诞。
- 自然与身体挑战：EBC 徒步、新西兰萤火虫洞、瑞士采尔马特。
- 童心与亲子：新西兰霍比特村、巴厘岛做饭和农场。
- 浪漫与人生仪式：卡帕多奇亚热气球、卡帕多奇亚骑马日落、EBC 珠峰大本营。
- 本地生活：伊斯坦堡红茶/咖啡/burek、巴厘岛市场和农场。
- 精神性和社群：清迈香巴拉音乐节、熊野古道社群徒步（目前细节不足）。

