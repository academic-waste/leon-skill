# ChatGPT Quick Evidence

This file is a compact evidence map for environments that cannot run `scripts/search_evidence.mjs`, especially ChatGPT web Skills. Use it to quickly ground answers, then open the topic reference for fuller reasoning.

Do not treat this file as a replacement for the full references. It only lists high-utility evidence cards and citations.

## How To Use

1. Match the user's question to one or two themes below.
2. Use the claim to shape the answer.
3. Cite the source title, timestamp, and URL exactly.
4. If a card says `needs_review`, mention that the evidence comes from Whisper subtitles and may need later transcript review.
