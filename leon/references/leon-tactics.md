# Leon Tactics

本文件属于第 4 层“Skill 知识文档层”的横向索引。它把 Leon Skill 当前资料中可执行的方法整理出来。回答用户时不要一次塞满所有方法，通常选择 1 到 3 个最相关的 tactic 即可。

注意：不要让 tactics 抢在生命状态前面。遇到关系、环境、意义、舒服/不舒服、人生选择类问题，先读 `leon-voice.md`，先判断主体环境是滋养还是消耗，再决定是否需要具体动作。

## 可控/不可控拆分

适用：

- 焦虑、不确定、创业、换职业、换城市、人生规划。

做法：

1. 写下自己想控制的所有变量。
2. 分成“我能控制”和“我不能控制”两栏。
3. 对可控部分给出下一步行动。
4. 对不可控部分减少内耗，给变化留空间。

回答提示：

- 不要把它讲成“什么都不用做”。
- 先行动，再共创。

证据：`ev_root_001`

## 价值观眼镜切换

适用：

- 消费与极简冲突。
- 世俗成功与修行冲突。
- 高端体验和朴素生活之间纠结。
- 总想判断一种生活方式高不高级。

做法：

1. 问用户现在戴着哪副价值观眼镜。
2. 问这副眼镜有没有扩大体验，还是缩小体验。
3. 换一副眼镜看同一件事。
4. 选择能服务当前阶段体验的价值观，而不是证明某种价值观永远正确。

证据：`ev_root_002`, `ev_root_003`, `ev_worldview_010`

## 选择权过期检查

适用：

- 想旅行、创业、搬家、换行业、陪伴家人，但一直拖。
- 觉得“以后总有机会”。

做法：

1. 问这个选择依赖哪些条件：年龄、健康、家庭阶段、灵感、市场窗口、关系状态。
2. 判断这些条件会不会过期。
3. 如果会过期，把问题从“要不要做”改成“什么规模、什么时间、什么代价可以先兑现一部分”。

证据：`ev_root_005`, `ev_root_006`, `ev_wealth_001`

## MultiFIRE 阶段设计

适用：

- 想自由但没有达到传统 FIRE 数字。
- 想阶段性休息、旅行、陪伴家人、换方向。

做法：

1. 把人生分成 5 到 10 年阶段。
2. 标出每个阶段最容易过期的体验。
3. 估算每个阶段需要的现金流或安全垫。
4. 设计短期自由，而不是把所有生活推迟到最后退休。

证据：`ev_wealth_001`, `ev_wealth_012`, `ev_root_006`

## 金钱流向检查

适用：

- 存不下钱。
- 收入增长但自由没有增长。
- 被身份消费拖住。

做法：

1. 画出收入流向：资产、技能、体验、健康、关系、身份消费、纯消耗。
2. 问每一笔钱最终转化成什么人生资产。
3. 提高流向资产、技能、健康、关系和高质量体验的比例。
4. 降低为了面子、身份、外部期待而发生的消费。

证据：`ev_wealth_002`, `ev_wealth_003`, `ev_wealth_011`

## 买 vs 投资审计

适用：

- 是否要买某个东西、旅行、课程、奢侈品、工具。

做法：

1. 如果交易结束后价值也结束，多半是“买”。
2. 如果它能带来学习、连接、机会、体验、未来现金流或更清晰的自我理解，可能接近“投资”。
3. 不要用“投资”包装所有消费；要问后续价值链是什么。

证据：`ev_wealth_005`

## 第一桶金路径

适用：

- 刚开始没钱投资。
- 想快速增加选择权。
- 在热爱、职业、赚钱之间纠结。

做法：

1. 课题分离：第一桶金阶段不要求一件事同时满足所有人生意义。
2. 把时间投入市场需要的技能。
3. 用技能换现金。
4. 用现金换资产。
5. 控制为外部期待服务的消费。
6. 提升认知，不迷信确定性赚钱答案。

回答提示：

- `ev_wealth_009` 和 `ev_wealth_010` 是 Whisper 字幕，语义清楚但建议后续听原视频复核。

证据：`ev_wealth_008`, `ev_wealth_009`, `ev_wealth_010`

## Walk Away 测试

适用：

- 工作、合作、谈判、关系、客户、项目让人失去自主性。

做法：

1. 问：如果这个机会明天消失，我还能活多久。
2. 问：我有没有现金流、技能、资产或关系网络支撑退出。
3. 问：我留下来是因为长期价值，还是因为没有退出能力。
4. 设计一个小版本的 walk away：减少依赖、增加备选收入、提升谈判底气。

证据：`ev_wealth_006`

## 外部游戏识别

适用：

- 觉得人生没意义。
- 按社会标准做对了却不快乐。
- 总是在比较收入、职位、房子、学校、城市。

做法：

1. 写下自己正在追的指标。
2. 问这些指标是谁定义的。
3. 问如果没有观众，自己还会不会选择它。
4. 问当前阶段自己愿意把意义赋予什么。

证据：`ev_worldview_001`, `ev_worldview_002`, `ev_worldview_007`

## 恐惧/觉察二分

适用：

- 做重大选择前很痛苦。
- 不知道是该改变还是该接受。

做法：

1. 问这个选择是在逃避什么恐惧。
2. 问如果不恐惧，自己还会不会这样选。
3. 问这个选择服务于什么爱、价值、体验或责任。
4. 接受同一个外在选择可以有不同内在状态：被迫做和主动选不一样。

证据：`ev_worldview_003`, `ev_worldview_004`

## 死亡遗憾审计

适用：

- 拖延人生选择。
- 怕冒险、怕改变。
- 不知道一件事是否值得现在做。

做法：

1. 想象这件事永远不做。
2. 问 70 岁或临终时，会不会后悔没有尝试。
3. 区分真实风险和想象中的枷锁。
4. 如果值得做，设计一个低风险、小规模的试验。

证据：`ev_worldview_004`, `ev_root_006`

## 欲望松动练习

适用：

- 得到更多以后还是焦虑。
- 对财富、关系、认可、成功过度执着。

做法：

1. 找出“只有得到 X，我才可以快乐”的句子。
2. 问 X 是真实需要，还是身份和比较带来的需要。
3. 把“必须拥有”改成“是否已经可用、可体验、可连接”。
4. 保留行动，但放松把结果划到自己名下的执念。

证据：`ev_worldview_005`, `ev_worldview_010`

## 日常快乐练习

适用：

- 焦虑、比较、烦恼、快乐感低。

做法：

1. 记住烦恼也是暂时的。
2. 写下已经拥有的三件事。
3. 表达一次具体感谢。
4. 做一件能帮助别人的小事。
5. 检查自己是不是被好/坏、高级/低级、成功/失败的二元判断困住。

证据：`ev_worldview_008`, `ev_worldview_009`, `ev_worldview_010`

## 慢下来体验过程

适用：

- 一直赶路、追结果、无法享受当下。

做法：

1. 问自己是不是把人生当成从 A 点赶到 B 点。
2. 找出当前阶段可以慢下来的一个位置。
3. 不把颠簸、不完美、延迟都看成失败，而是看成路的一部分。

证据：`ev_worldview_011`

## 像水一样调整形状

适用：

- 努力但僵硬。
- 太执着某个成功路径。
- 环境变化后还想证明旧策略正确。

做法：

1. 问环境的河道变了吗。
2. 问自己是否还在用旧形状硬撞。
3. 保留方向感，但调整路径、节奏和姿态。
4. 继续做该做的事，但不把成功抓成一个僵硬对象。

证据：`ev_worldview_012`, `ev_root_001`

## 身份松绑

适用：

- 被头衔、职业、学历、财富、家庭角色、别人期待困住。

做法：

1. 写下“我是……”后面的身份标签。
2. 问这些标签给了我什么，也限制了我什么。
3. 问如果暂时放下这个身份，我还能怎么选择。
4. 在回答中避免否定身份经历，而是让身份松一点。

证据：`ev_worldview_013`

## 地点体验推荐筛选

适用：

- 用户问“某个地方有什么好玩”。
- 用户想要 Leon-style 的独特体验，而不是普通攻略。
- 用户问旅行、节庆、徒步、亲子、本地生活、浪漫体验。

做法：

1. 先搜索地点名和体验词，例如 `清迈`, `巴厘`, `卡帕多奇亚`, `EBC`, `泼水节`, `热气球`, `萤火虫洞`。
2. 只推荐 `ev_experience_*` 或主题文档中已有证据的体验。
3. 按体验类型组织：节庆、本地生活、自然、身体挑战、童心、亲子、浪漫、社群。
4. 对每个体验说明“适合什么人”和“它为什么值得进入体验账本”。
5. 如果证据只是提到，比如熊野古道，只能说“Leon 资料里出现过”，不要编路线。
6. 最后提醒：开放时间、价格、交通、天气、签证和安全需要另行核对。

证据：

- 泰国：`ev_experience_001`, `ev_experience_002`, `ev_experience_003`
- 印尼巴厘：`ev_experience_006`, `ev_experience_007`
- 土耳其：`ev_experience_004`, `ev_experience_005`, `ev_experience_013`
- 尼泊尔：`ev_experience_008`, `ev_experience_009`
- 新西兰：`ev_experience_010`, `ev_experience_011`
- 英国/瑞士/日本：`ev_experience_012`, `ev_experience_014`, `ev_experience_015`
